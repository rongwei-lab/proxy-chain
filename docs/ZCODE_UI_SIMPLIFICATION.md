# proxy-chain 页面简化开发任务书

- 交付对象：Zcode。
- 编写日期：2026-11-15。
- 状态：待开发；本文为需求与验收规范，不代表页面已改版。
- 目标：默认只展示“导入节点 → 选择链路 → 下载配置”，减少操作项和说明文字，高级功能按需展开。

## 1. 范围与实施原则

本轮改造前端交互、布局与文案，沿用当前 React、TypeScript、CSS 和组件体系。保留节点解析、归一化、来源管理、链路组装、校验、导出与后端能力检测逻辑，不新增后端接口或 UI 组件库。

当前工作区存在已完成修复但尚未提交的改动及未跟踪文件。开始前先检查 `git status`，以实际工作区为基线，不用旧提交覆盖现有实现。此前开发与修复文档中的功能要求继续有效；页面布局和文案以本文为准。

关键约束：

- 页面步骤、折叠状态属于 UI 状态；不能通过修改 `plan.mode`、节点选择或启用状态来实现隐藏。
- 现有多入口、可选独立出口、多跳中转、多方案、自定义规则、保存恢复及各类导出仍可访问。
- 收起高级设置、切换步骤、切换语言均不得改变生成配置。
- 真实来源不自动选择第一个节点；“试用示例”可沿用示例预选。不得因校验失败自动改成直连或扩大服务端订阅白名单。
- 不自动保存凭据，不增加分析上报或把输入写入 URL、控制台和本地存储。

## 2. 页面结构与操作流程

### 2.1 默认结构

```text
链式代理实验室                         中文 / English   高级设置
导入节点，组合链路，生成 Mihomo 配置

① 导入节点  →  ② 选择链路  →  ③ 下载配置

[当前步骤内容]

上一步                                      下一步 / 下载配置
```

- 默认只展开当前步骤，其他步骤显示在进度导航中，不继续把所有配置表单并排铺开。
- 首次访问进入第 1 步；顶部不出现空节点导致的大段红色导出错误。
- 步骤 1、2 的主要导航按钮为“下一步”；步骤 3 的主要按钮为“下载配置”。“导入”保留在输入区内。
- 已访问步骤可以返回；向前进入步骤 2 需节点库至少有一个有效节点，进入步骤 3 需当前链路必选项完整。
- 第 1 步空节点库时禁用“下一步”并说明原因；第 2 步允许点击“下一步”触发校验，不完整时留在本步并定位错误。
- 按钮不可用时，在附近显示一句具体原因，例如“请先导入节点”，不能只呈现灰色按钮。
- 返回上一步不丢失节点、方案、筛选、未提交输入和手动表单草稿；异步请求不因视图卸载而失控或覆盖新状态。
- 切换步骤后把焦点移至该步骤标题；不要自动跳步、自动滚到页面末尾。

### 2.2 高级设置入口

页头保留一个始终可用的“高级设置”入口，使用可折叠面板，内部按组展开：

| 分组 | 内容 |
| --- | --- |
| 链路与分流 | 基础/多跳编排、添加与排序中转层、各层选路策略及探测参数、分流模板与自定义规则 |
| 方案管理 | 选择、新建、重命名、复制、删除方案；方案 JSON 导入与导出 |
| 本机保存 | 保存、恢复、清除，以及是否包含节点凭据 |

- 没有节点时也能打开高级设置，使用 JSON 导入和本机恢复。
- 高级面板收起后仍保留正在生效的配置；步骤 2、3 显示当前方案名称与简短摘要，例如“2 个入口 · 1 层中转 · 独立出口 · 国内直连”。
- 若当前方案为多跳或使用自定义规则，显示“多跳链路”或“自定义分流”标记，点击可展开对应设置。
- 已启用中转层的节点选择与缺失提示必须可见或一键展开，不能出现“高级设置藏住了必填错误，用户无法继续”。
- 只有用户明确切换基础/多跳编排时，才沿用现有 `plan.mode` 的业务行为。收起面板不等于切换为基础链路。

## 3. 第 1 步：导入节点

### 3.1 统一输入

默认只展示一个多行输入框和“导入”按钮。

- 输入框标签：“订阅地址或节点内容”。
- 占位提示：“粘贴一个订阅地址、节点链接或 Clash YAML”。占位文字不能代替可访问标签。
- 来源名称不再是默认必填操作，使用现有自动命名；自定义名称放入“更多方式”。
- “更多方式”中保留手动添加、试用示例、来源命名和订阅拉取选项。
- 保持已有协议支持范围；不通过 UI 改造承诺新增协议或解析格式。

输入分派规则：

| 输入 | 行为 |
| --- | --- |
| 去除首尾空白后，完整内容恰好为一个合法 HTTP(S) 地址 | 点击“导入”后调用已有订阅拉取流程 |
| 节点 URI、多行节点内容或 Clash YAML | 调用已有本地解析流程 |
| 多个订阅地址，或订阅地址与节点内容混贴 | 提示“请单独导入订阅地址或节点内容”；本轮不新增批量订阅网络调度 |
| 空白或无法识别的内容 | 保留输入，显示一句具体错误，不写入节点库 |

识别不能把 YAML 内的 `url`、`server` 等字段当作订阅地址，也不能把 VLESS、SOCKS、SS、HY2 节点链接当作待抓取网页。无法确定类型时要求用户拆开输入，不尝试遍历其中的 URL。自动识别本身不发起请求，只有点击“导入”才执行。

### 3.2 反馈与来源列表

- 导入中按钮显示“导入中…”，阻止重复提交同一请求。
- 成功后停留本步，简短显示“已导入 12 个节点”；来源行显示各来源有效数量，节点库总数按去重后的实际数量计算。
- 部分内容有问题时显示“已导入 12 个节点，3 项未导入”，提供“查看详情”；不能把部分成功显示成全部成功。
- 失败时保留输入和已有节点，提供重试；成功后才清空已提交输入。
- 来源默认用紧凑列表显示“名称、节点数、状态”，刷新、取消、删除及解析详情按需展开。
- 删除影响确认、撤销、订阅刷新竞态保护和“失败保留旧节点”的现有行为继续有效。
- 示例按钮改为“试用示例”，加载后提示“示例节点仅用于演示，无法连接”。

### 3.3 订阅拉取设置

- 默认沿用现有自动拉取方式，不要求普通用户先理解 CORS、服务地址或 Token。
- 拉取方式、外部服务地址与 Token 进入“更多方式 → 订阅拉取选项”，保留原有能力。
- 后端检测失败不阻断本地粘贴解析；浏览器直连仍遵循原有能力和失败处理。
- 拉取失败显示可执行的短提示，再提供可展开的详情；不把服务端错误改写成“导入成功”。
- 错误消息和来源列表不展示完整敏感订阅 URL、访问令牌或节点密码。

## 4. 第 2 步：选择链路

### 4.1 默认内容

仅展示入口选择、独立出口开关、必要时的出口选择，以及紧凑链路预览。

- 入口使用复选框，保留多选；默认标题为“入口节点”，旁边显示“已选 N 个”。
- 节点行优先显示别名、协议和来源；服务器、端口和重命名放在“详情”或行内更多操作中，不展示凭据。
- 节点搜索保留，提示简化为“搜索节点”；协议与来源筛选放进“筛选”。
- 全选与清空移入批量操作，继续遵循“只操作当前筛选结果”等已有语义。
- 选路策略默认不展开；非默认策略在该层标题附近显示短标签，点击进入高级设置。
- 新建方案默认值沿用当前实现：独立出口开启、手动切换、国内直连；不要因视图改造重置已有方案的配置。

### 4.2 独立出口

- 使用一个“使用独立出口”开关控制出口选择区域。
- 关闭后收起出口列表，保留原选择，预览与所有导出不含该独立出口层。
- 基础链路关闭独立出口后，预览为“本机 → 入口 → 目标网站”。
- 多跳链路关闭独立出口后，最后一个启用中转层是最终出口，不能把整条链路错误缩减为入口。
- 重新开启后恢复原选择；已经失效的引用仍提示处理，不假装恢复成有效节点。
- 开关附近无需长段停用说明，可用一行“已关闭独立出口”。

### 4.3 预览与校验

- 标题使用“当前链路”，移除“实时”“拓扑”等容易让用户误认为有实际连通性检测的表述。
- 默认展示层名称、已选数量和最终出口，多个候选节点不在图中全部展开。
- 用户尝试进入下一步后，在对应层显示“请选择入口节点”“请选择出口节点”等错误；已失效引用等实际异常仍须及时提示。
- 下一步校验所有正在生效的必选层，包括中转层；未启用层不因保留的空选择而阻断导出。
- 不改写既有导出校验规则。第 3 步仍以真实导出结果是否有效决定能否下载。

## 5. 第 3 步：下载配置

### 5.1 主操作

- 默认目标为“Mihomo（Clash Meta）”，主要按钮“下载配置”，次要按钮“复制配置”。
- 显示紧凑链路与分流摘要，并保留“返回修改”。
- YAML 默认折叠，通过“查看配置”展开。复制、下载直接使用当前计算结果，不要求先展开预览。
- “已复制”“下载失败”等结果在操作附近反馈；复制失败不能显示成功。
- 仍有阻断错误时禁止对应导出，并显示“需要处理 N 项”及逐项“前往修改”；跳转需展开目标层或高级设置并定位焦点。
- 非阻断兼容性警告可以折叠，但要显示数量或摘要，不静默消失。

### 5.2 更多导出

将原来并列的多个页签改成“更多导出”，按需打开：

| 入口 | 必须保留的行为 |
| --- | --- |
| 配置片段 | 保留现有片段生成与合并说明，说明默认折叠 |
| 节点链接 | 保留按当前方案或节点库选择；明确“不包含链式关系” |
| 批量下载 | 保留按方案校验与结果，不能因当前方案有效就跳过其他方案错误 |
| 临时导入链接 | 保留能力检测、上传前提示、有效期、旧链接失效/过期及配置变更提示 |
| 客户端使用帮助 | 放置 v2rayN、Shadowrocket 等现有兼容说明；不新增已实测承诺 |

临时链接不可在进入步骤 3、展开菜单或修改节点时自动生成。只有点击明确的生成按钮才上传；缺少后端能力时只在该入口给出短提示，不占据普通下载流程。

## 6. 文案与说明删减

### 6.1 默认页面的删减清单

| 当前内容 | 本轮处理 |
| --- | --- |
| “多来源节点归一化、可视化多跳串联……”等副标题 | 改为“导入节点，组合链路，生成 Mihomo 配置” |
| 页面顶部大段本地处理说明与重复的“纯本地运行”标签 | 移除重复展示；帮助中保留完整说明，网络行为在操作处说明 |
| “节点来源与归一化节点库” | 改为“导入节点” |
| “方案编排与链路设置” | 改为“选择链路” |
| “校验与配置导出” | 改为“下载配置” |
| 每个区块下的重复功能介绍 | 默认删除，不用新的长说明替换 |
| “入口层 / 入口节点”“独立出口 / 最终出口 / 独立出口”等堆叠标签 | 保留一个标题和必要状态，减少同义重复 |
| `select`、`url-test`、`fallback`、规则模板内部标识 | 默认显示中文名称；技术值仅在高级设置或配置预览中出现 |
| `sub:on · tmp:on`、同源 API 路径、存储实现名称 | 移入高级设置中的“环境状态”，普通流程不展示 |
| DNS 与配置片段的长说明 | 放在“配置说明”中，默认折叠 |
| 客户端兼容性长段落 | 放在“客户端使用帮助”中，目标相关的必要限制仍就地显示 |
| 成功导入后的完整统计长句 | 改为“已导入 N 个节点”，异常详情按需展开 |

页面常驻帮助以一句话为主，避免重复说明按钮已经表达的动作；进度导航、标题、按钮及输入标签不计入帮助文案。技术原理、协议支持清单和完整说明可放入帮助，保持可查。

### 6.2 必须在相关操作前可见的提示

减少文字不等于隐藏影响用户决定的信息。以下短提示不能只藏在帮助、悬浮提示或点击后的结果里：

| 场景 | 建议短文案与要求 |
| --- | --- |
| 统一输入被识别为订阅地址 | “将联网获取订阅内容。”若使用后端代拉，还应说明地址将发送到所选拉取服务 |
| 生成临时链接 | “含节点凭据的配置将上传至 Cloudflare；链接 10 分钟内持有者可读，平台备份可能保留更久。”同时保留完整存储说明入口 |
| 勾选保存节点凭据 | “节点凭据将明文保存在此浏览器。”默认不勾选 |
| 默认保存方案结构 | “仅保存方案结构，恢复后需重新导入节点。” |
| 导出普通节点链接 | “节点链接不包含链式关系。” |
| 使用尚未实测的客户端 | 明确尚未实测，不写成已兼容或保证可用 |

- 临时链接有效期继续读取现有实现/接口约定；“10 分钟”对应当前 600 秒。不要把链接到期写成云端全部数据和备份已彻底删除。
- 完整存储与客户端说明沿用已核实内容；UI 简化不得自行缩短真实数据保留期或扩大兼容承诺。
- 说明应说明实际行为：本地解析/下载不上传，订阅代拉与临时链接会联网，不再笼统宣称全部纯本地。
- 中文和英文同步调整，复数、数量插值和可访问标签保持正确，避免英文界面残留新增中文。

本轮不要求更改 schemaVersion、持久化格式、节点身份计算、SSRF 防护、Worker 绑定或部署配置。此前的特殊引用防护、来源撤销、历史别名迁移与上传链接配置变更提示不得回归。

### 7.1 响应式与可访问性

- 桌面端可以给步骤 2 配置窄预览区；不恢复为所有配置同时展开的双列长页面。
- 375px 宽手机界面使用单列，正文与按钮无横向溢出；配置代码仅在自身容器内滚动。
- 折叠区中的控件不进入键盘焦点顺序，展开按钮具有 `aria-expanded`，当前步骤具有可访问的状态标记。
- 不仅依赖颜色、悬浮或图标表达按钮含义；更多操作和节点详情支持键盘与触屏。
- 若保留底部固定操作区，要为内容预留空间；屏幕键盘出现时不能遮住输入或主要按钮。

## 8. 验收用例与交付证据

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| U01 | 首次打开 | 只展示第 1 步主体，无空节点红色错误墙；高级设置可访问 |
| U02 | 分别导入单个 HTTP(S) 地址、节点链接、多行节点与 YAML | 进入正确流程；本地内容不触发订阅请求，YAML 内 URL 不被误抓取 |
